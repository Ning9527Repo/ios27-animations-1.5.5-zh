# 27banner animation

Standalone reconstruction of the iOS 27 notification banner animation path.

The project does not embed, load, patch, or redistribute GlassSuiteX. It uses
only independently written source and public framework declarations, with
behavior reconstructed from authorized static analysis of GlassSuiteX 1.1-0.

Attribution: the original GlassSuiteX implementation was authored by wkk.
